Power BI · Portfolio project

Revenue Leakage & Retention Dashboard

A four-page Power BI report built from 138,116 orders, 2021–2025. Numbered markers on each page match the build steps below. Every figure is from the real dataset.

Design rules used on every page

Titles state the finding

A reader should get the point without reading the chart.

✗ Revenue by status✓ 27% of booked revenue never becomes cash
One default color

Everything is blue. Orange means "focus here", red means "problem", green means "good outcome".

✗ A different color per bar✓ Blue bars with the 35%+ band in red
Labels, not gridlines

Turn on data labels and turn off gridlines and the value axis on bar and column charts.

✗ Gridlines every $500K✓ $14.3M printed on the bar
KPIs first, detail after

The card row answers "how are we doing?" The charts below answer "why?"

✗ A table at the top of the page✓ 4–5 cards, then charts
Consistent grid

Align every visual to the same edges with 10px gaps. Use View → Gridlines and Snap to grid.

✗ Visuals at random sizes✓ Equal heights on each row
No chart junk

No pie charts with more than 3 slices, no 3D, no two y-axes on one chart.

✗ Donut with 8 segments✓ Sorted horizontal bar
